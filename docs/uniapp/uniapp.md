# 健身门店业务文档（小程序）

> 适用范围：会员端、员工版、管理者版、总部管理版小程序。
>
> 整理说明：本文档依据三页手写需求整理补全，保留原始需求口径，仅做条目化、分组与明显笔误修正（如“实施到店人数”→“实时到店人数”、“验卷”→“验券”、“教练段”→“教练端”、“会卡”→“会员卡”、“总数居”→“总数据”、“训训练计划”→“训练计划”）。原文表述存疑处集中列在文末「七、待确认事项」。

## 一、端与版本概览

| 端 | 说明 |
| --- | --- |
| 会员端小程序 | 会员自助使用：首页、预约、我的 |
| 员工版小程序 | 首页不变；预约界面看自己的预约；我的 → 工作台 |
| 管理者版本小程序 | 首页不变；预约界面看门店的预约；我的 → 工作台 |
| 总部管理版本小程序 | 门店/分店数据汇总、审批管理、门店工资表 |

## 二、小程序通用规则

### 1. 入场推送规则

| 入场人员 | 推送对象 |
| --- | --- |
| 会员（店长/负责人名下） | 所有会员入场全部收到推送（店长/负责人） |
| 会员（私教员工名下） | 只推送【自己名下负责的会员】入场（私教员工） |
| 陌生新客/潜在客户 | 只推送给店长，不推给员工 |

### 2. 门禁与风控规则

- 会员一人一刷脸，禁止代刷。
- 30 秒内同设备多人入场自动报警。
- 会员带人次数统计（超 3 次冻结卡）。
- 黑名单门禁拦截。
- 夜间异常逗留超时提醒。
- 欠费禁止入场机制（ab 门除外）。

### 3. 会员端入口规则

- 从小程序点进去，照片封面提示。
- 会员不管有没有卡，留过电话登录后就记录为潜在客户。

## 三、会员端小程序

### 1. 首页

1. 环境照片/视频
2. 门店名称/切换分店
3. 门店简介与小框写面积与特色项目
4. 门店地理位置
5. 实时到店人数
6. 团购验券
7. 匿名反馈
8. 微信连续包月
9. 在线购买会员卡
10. 我的会员卡信息
11. 监控画面
12. 客服信息

### 2. 预约

1. 教练信息照片 + 点进去看详情介绍 + 可预约（教练端自己上传和查看预约）。
2. 在线购买私教课，买完可预约教练，预约刷脸自动签课（管理者或教练可发链接修改价格，教练只能提交改价申请）。

### 3. 我的

页面入口：

- 下载 App 提醒提示：下载送什么。
- 加盟咨询：品牌资料简介、加盟电话与提交意向信息、3 种模型门店立体图。

功能列表：

1. 信息 - 头像 - 系统名称昵称（点进去可修改人脸照片；手机号不能修改）。
2. 我的会员卡：点进去看到信息资料。
3. 待签约：点进去可签署发放的电子合同，并查看合同记录。
4. 扫码签课（先签到后扫码）。
5. 体测数据记录 - 训练计划（教练上传）；个人运动档案永久保存（行业护城河，别人没有）。
6. 本月签到 x 次 / 所在门店排名。
7. 邀请或消费得积分 - 消费积分兑换会员卡。
8. 匿名门店评分评价与建议。
9. 活动报名 - 门店活动发起 - 会员一键报名。
10. 扫码器械教学。

## 四、员工版小程序

1. 首页不变。
2. 预约界面：看自己的预约。
3. 我的下面变成工作台，包含：

    - 自己负责的会员
    - 本月业绩
    - 潜在客户与跟进
    - 本月签课
    - 签课二维码（会员扫这个码）
    - 自己负责的会员体测记录（可上传）
    - 自己负责的会员合同记录
    - 训练计划上传
    - 自己负责的会员预约记录
    - 自己负责的会员排课
    - 当天签课数量与昨日
    - 签到记录（实时更新，可查指定日期总入场）
    - 个人工资表
    - 审批功能
    - 私教课产品链接与改价申请
    - 管理员审批

## 五、管理者版本小程序

1. 首页不变。
2. 预约界面：看门店的预约。
3. 我的下面变成工作台，包含：

    - 销售明细：可查时间、产品汇总、金额汇总
    - 当日业绩：会员卡多少/平均、私教多少/平均、当天数量、当天新客户、消课数量、本月总消课
    - 总业绩：可以看到每个人的业绩/平均业绩
    - 总会员（可分配客户；找到会员可查看具体信息与私信）
    - 总私教会员（找到会员可查看具体信息与私信）
    - 临近到期会员卡（找到会员可查看具体信息与私信）
    - 临近到期私教（找到会员可查看具体信息与私信）
    - 会员分配
    - 审批管理
    - 门店员工业绩排名
    - 门店员工平均业绩
    - 当天签到数量与昨日
    - 签到记录（实时更新，可查指定日期当天）
    - 私教课产品链接与改价
    - 发卡 - 会员卡 - 私教卡 - 发合同
    - 体测记录（可上传）- 合同记录 - 训练计划
    - 会员反馈汇总 - 评价汇总 - 远程开门 - 远程开柜
    - 门店工资表

## 六、总部管理版本小程序

管理者能看到的汇总：

- 可以看分店总数据。
- 所有门店总数据汇总。
- 审批管理。
- 门店工资表。
- 总业绩：可以看到每个店每个人的业绩/平均业绩。
